# Drivo - Car Rental (React, frontend only)

Demo project. No backend. Bookings, payments and login (added in later stages) are simulated and stored in your browser's localStorage only.

## Run on Windows PowerShell
```powershell
cd client
npm install
npm run dev
```
Open the localhost URL shown in the terminal (usually http://localhost:5173).

## Progress
- Stage 1: setup, styles, navbar, footer, home page, routing (done)
- Stage 2: 14 sample cars, listing, search, filters, sorting, load more (done)
- Stage 3: car details, gallery, price estimator, favorites (done)
- Stage 4: multi-step booking, validation, price calculation, localStorage bookings, confirmation (done)
